# Лабораторная работа 3

1. Создайте форк этого репозитория в своём GitHub-профиле.
2. Перейдите в созданный форк и откройте **Settings → General → Features**.
3. Включите **Issues** и убедитесь, что создание новых Issues разрешено всем пользователям (не выбран режим `Collaborators only`).
4. Сообщите преподавателю свою ссылку на GitHub.
5. Ждите появления Issue с вашим индивидуальным заданием. Оно появится во вкладке **Issues** вашего форка.

## Условия выполнения

Результатом выполнения задания является репозиторий, готовый к запуску командой `docker compose up -d`. В `README.md` должна находиться инструкция по работе с приложением.

Каждое задание подразумевает использование бекенда из репозитория https://github.com/nelkor/moscow-events. Вы разрабатываете только фронтенд и `compose.yml`.

Фронтенд можно вайбкодить, его особо защищать не придётся, лишь бы он был +/- адекватным. Надо будет защитить `README.md` и `compose.yml`.
